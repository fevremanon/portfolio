# Portfolio — Manon Fèvre

Site statique (HTML/CSS) hébergé sur Vercel.

- `index.html` : contenu du site
- `style.css` : mise en forme
- `images/` : visuels des projets (à ajouter)

Pour remplacer un visuel de projet, mets l'image dans `images/` et remplace le `<span>` du bloc `project-visual` par `<img src="images/nom.jpg" alt="...">`.
